# Student Management System

The Student Management System is a SQL Server database project designed to manage student information, departments, course enrollments, attendance records, and examination results.

This project demonstrates core database concepts including database design, normalization, relationships, constraints, views, stored procedures, user-defined functions (UDFs), transactions, and reporting queries.

## Features Implemented

### Database Design
- Relational database schema
- Primary Keys
- Foreign Keys
- Referential Integrity

### Constraints
- PRIMARY KEY
- FOREIGN KEY
- CHECK Constraint
- DEFAULT Constraint
- NOT NULL
- UNIQUE

### SQL Queries
- INNER JOIN
- Aggregate Functions
- GROUP BY
- HAVING
- Subqueries
- Reporting Queries

### Views
- StudentDepartmentView
- StudentMarksView
- CourseEnrollmentView

### Stored Procedures
- GetStudentMarks
- GetStudentsByDepartment
- GetStudentAttendance
- GetDepartmentStudents

### User Defined Functions (UDFs)
- CalculateGrade
- IsPass
- GetPerformanceLevel
- CalculateAttendanceStatus
- GetAverageMarks

### Transaction Management
- BEGIN TRANSACTION
- COMMIT
- ROLLBACK
- SAVEPOINT

## Technologies

- SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Database Schema

Departments | Students | Courses | Enrollment | Attendance | Examinations
